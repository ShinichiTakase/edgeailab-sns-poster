# 公開サイトSEO（2026-10-04）

## 外部仕様

検索対象はトップ、機能、料金、FAQ、プライバシーポリシー、利用規約、特商法表記の7ページ。公開情報・デザイン・登録導線を維持し、タイトルと説明でSNS予約投稿・AI投稿文生成のサービス内容を明示する。

ログイン、登録、認証、招待、投稿・スケジュール、請求・支払い、アカウント設定等のアプリ画面は検索対象外。アクセス制御は従来の認証・権限チェックで行い、noindexを認証の代わりにはしない。

トップページの旧リリース予定日は日付を含まないサービス名に変更。対応SNS数5・無料トライアル30日はHTMLの初期値にも記載する。予約投稿数の表示は従来の「無制限」を維持するが、トライアル60通・1スケジュール1日3回等の制約は別途適用される。

## 内部仕様

- 公開7HTML: 固有title/description、HTTPSのcanonical、OG、Twitter Card、WebPageを追加。トップはWebSiteと既存Organizationを関連付ける。
- 既存FAQPageは回答表示との整合性を検査する。FAQリッチリザルトの表示を保証しない。
- 料金のSoftwareApplication/Offerは根拠のないpriceValidUntilを削除し、表示価格が税抜月額基本料金で従量料金等が別途必要である旨を補足する。
- sitemap.xmlは上記7URLのみ、今回編集したページのlastmodを2026-10-04とする。ログイン・登録と内容未監査のPDFを掲載しない。
- アプリHTMLに`noindex, nofollow`を追加。既存管理画面の同指定は維持。
- APIサーバーは`X-Robots-Tag: noindex, nofollow`を全レスポンスへ付与する（OAuth callback・アップロード含む）。本番適用にはAPI配備が必要。
- robots.txtはクロールを許可する既存設定を維持し、Googleがnoindexを読み取れるようにする。
- 公開4ページの法定リンクに実HTMLへのhrefを設定し、従来のモーダル開閉も維持する。
- CSS/JSアセットは変更していないため、既存ハッシュ付きURLを保持する。

HTTPリダイレクト・wwwのDNS/証明書・Search Consoleの登録状態は外部設定であり、このHTML変更では変更しない。
