# Facebook Pageリール（2026-10-15、未公開）

継続スケジュールの投稿SNSで「Facebook（通常）」「Facebook（リール）」「Instagram（リール）」を独立して選べる。Facebookは連携済みPageのみ対象で、複数Pageがあれば投稿先を選択する。通常投稿とリールを同時選択できる。

FacebookリールとInstagramリールは1組の動画・キャプションを共有する。両方を選んでも動画生成タブ・生成本数は増えない。既存の背景指定、進捗表示、キャンセル、再生成、プレビューを使用する。動画は共通でも、各投稿先の成否と投稿数は別に扱う。Facebook通常投稿は従来の本文・リンクカードを使用する。

動画内にタイトルと「詳細はプロフィールのリンクから」を常時表示する。この案内はプロフィールリンクを設定する機能ではない。長文は読みやすい速度のエンドロールとし、最後の行が表示されてから4秒保持する。許容尺を超える場合は短文化して再生成する。本文の無断切捨てはしない。未対応絵文字は明示的エラーとする。

実際のタイムライン、カバー採用、端末による切り抜きはMeta側の処理にも依存する。プレビューと完全に同じ表示は保証しない。ワンショット投稿画面は今回の追加対象に含めない。
