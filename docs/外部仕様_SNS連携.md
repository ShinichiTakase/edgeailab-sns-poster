# 外部仕様: SNS連携

最終更新日: 2026-08-25（更新: 連携解除時の未実行予約投稿キャンセルを反映）
コード参照: onboarding.html, js/sns-connections.js, dashboard.html（SNS連携状況・
プロフィールメニュー内SNS一覧）

## 概要

X・Threads・Facebook・InstagramのアカウントをOAuth連携し、投稿の自動化を行う機能。
連携・解除は`onboarding.html`（設定専用画面）とダッシュボードのSNS連携状況アイコンの
両方から行える。

**重要: 2026-08-22時点でFacebook・Instagram・Threadsは実質未公開（Meta審査上の
Dev Modeに限定）。一般顧客が実際に連携できるのはXのみ**（内部仕様参照）。

## 連携設定画面（onboarding.html）

リード文: 「連携するSNSアカウントを選択してください。いつでも追加・変更できます。」
＋警告文（赤字太字）「アカウントを持っていないプラットフォームには連携できません。」

- トライアル残り日数バッジ（表示があれば）: 「無料トライアル残り{n}日（プラン: {プラン名}）」
- プラットフォーム一覧: X → Threads → Facebook → Instagram の固定順
- 各行の状態表示（サーバー応答を必ず信頼し、フロント側では独自に計算し直さない設計）:
  - 連携済み: アカウント名＋緑バッジ「連携済み」＋「削除」ボタン
  - 近日公開（Dev Mode未許可）: 「近日公開予定です」＋クリック無効の「連携する」表示
  - プラン上限到達: 「プランの上限（{n}件）に達しています。プラン変更ページはこちら」
    （change-plan.htmlへのリンク）＋クリック無効の「連携する」表示
  - 連携可能: 実際にOAuth開始URLへ遷移する「連携する」リンク
- ページ下部の警告文（赤字太字）: 「同じメールアドレスで複数のアカウントをお持ちの方は、
  ご希望のアカウントに連携されていることを確認してください」

### 連携完了・エラー時の表示

- 連携成功（`?connected=platform`）: 「{プラットフォーム名}との連携が完了しました。」
- Dev Mode未許可でアクセス（`?snsError=coming_soon`）: 「{プラットフォーム名}は近日公開
  予定のため、現在は連携できません。」
- プラン上限超過（`?snsError=limit_reached`）: 「プランの接続可能SNS数の上限（{n}件）に
  達しているため、{プラットフォーム名}を連携できませんでした。」

### Instagramアカウント切り替え確認（`?instagramSwitch=...`）

既に連携済みのInstagramアカウントと異なるアカウントで再認証した場合、即座に
上書きせず確認を挟む（内部仕様参照: 2026-08-21に実際に発生した誤配信事故への対策）。

- 見出し「連携するInstagramアカウントの確認」
- 本文: 「現在『{旧アカウント名}』に連携されていますが、今回認証したのは
  『{新アカウント名}』でした。連携先をこちらに切り替えますか？」
- 「このアカウントに切り替える」ボタン → 確定
- 「キャンセル」ボタン → 何もせず`onboarding.html`へ戻る（保留中の切り替えは単に
  未使用のまま期限切れになる）
- 切り替え失敗時: 「切り替えに失敗しました。リンクの有効期限が切れている可能性があります。
  お手数ですが連携をやり直してください。」

## 連携解除

ダッシュボード・onboarding.html双方に共通の確認モーダル「連携解除の確認」。
本文: 「{プラットフォーム名}の連携を解除しますか？投稿の自動化が停止します。」
失敗時: 「連携解除に失敗しました。時間をおいて再度お試しください。」

**連携解除すると、そのプラットフォーム宛ての未実行（実行待ち）の予約投稿は自動的に
キャンセル（削除）される**（2026-08-25修正。スケジュール投稿由来・ワンショット投稿の
予約投稿由来の両方が対象。それまでは連携解除してもキャンセルされず、トークンが
無いまま実行時刻を迎えて投稿が失敗し続けるという不具合があった）。この挙動について
確認モーダル上に明示的な案内文言は無く、解除操作の一環として画面上の告知なく
静かに実行される（要確認事項参照）。**投稿済み**（実行済み・過去）の投稿には影響しない。

## プラン別の連携可能数

| プラン | 上限 |
|---|---|
| Basic | 1 |
| Standard | 3 |
| Advanced | 5 |

## プラットフォームごとの投稿形態の違い（他機能との連携メモ）

- Instagram: スケジュール投稿では**リール（動画）**として自動投稿、ワンショット投稿では
  **通常のフィード（グリッド）投稿**として公開される（詳細は各機能の外部仕様参照）

## 要確認事項

- Facebook・Instagram・Threadsは現状Dev Mode制限により一般顧客は連携できない。
  マーケティング上の訴求（「4つのSNSに対応」等）と実際の利用可否に齟齬がないか要確認
- 連携解除確認モーダルの文言「投稿の自動化が停止します」は、新規の自動投稿が
  行われなくなることは示しているが、**既に予約済みの投稿がキャンセルされる**ことまでは
  明示していない。連携解除の直前にスケジュール詳細・投稿一覧で予約内容を確認していた
  ユーザーが、解除後に予約が消えていることに気付かず戸惑う可能性がある。文言追加を
  検討の余地あり
