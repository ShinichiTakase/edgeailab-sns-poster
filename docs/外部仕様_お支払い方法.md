# 外部仕様: お支払い方法

最終更新日: 2026-08-22
コード参照: payment.html

## 概要

クレジットカードを最大2枚まで登録できる画面。1枚目（プライマリ）での決済が失敗した
場合のみ、自動的に2枚目（バックアップ）で決済を試みる仕組み。

見出し「お支払い方法」、リード文「クレジットカードを最大2枚まで登録できます。1枚目
（プライマリ）での決済が失敗した場合のみ、自動的に2枚目（バックアップ）で決済を
試みます。」

## 権限制限（管理者限定）

**管理者ロール以外はお支払い方法セクション自体が表示されない**（Stripe.js自体も
読み込まれない）。代わりに案内文が表示される: 「このページは管理者のみ閲覧できます。
お支払い方法の確認・変更が必要な場合は、アカウント管理者にご依頼ください。」

## カード一覧

各カード行: ブランド（VISA/Mastercard/AMEX/JCB/Diners/Discover/UnionPay）、
下4桁（`•••• {下4桁}`）、有効期限（`{MM}/{YYYY}`）、優先度pill（「プライマリ」/
「バックアップ」）、削除ボタン。

空状態: 「登録済みのカードはまだありません。」

「カードを追加」ボタン: 2枚登録済みの場合は非活性化＋ツールチップ「お支払い方法は
2枚まで登録できます」。

## カード追加モーダル

タイトル「カードを追加」。Stripe Elementsのカード入力欄（**郵便番号（AVS）欄は
非表示**、日本向けサービスのため不要と判断）。

ボタン: 「キャンセル」「登録する」（送信中「登録中...」）。**モーダルを閉じると入力
内容は必ずクリアされる**（キャンセル・外側クリック・Escape・登録成功のいずれの
理由でも）。

### カードエラーメッセージ（Stripe側のエラーコードに対応）

| コード | 表示文言 |
|---|---|
| card_declined | カードが拒否されました。カード発行会社にご確認いただくか、別のカードをお試しください。 |
| expired_card | 有効期限が切れています。カード情報をご確認ください。 |
| incorrect_cvc / invalid_cvc | セキュリティコード（CVC）が正しくありません。 |
| incorrect_number | カード番号が正しくありません。 |
| invalid_expiry_month | 有効期限（月）が正しくありません。 |
| invalid_expiry_year | 有効期限（年）が正しくありません。 |
| incomplete_number | カード番号を入力してください。 |
| incomplete_cvc | セキュリティコード（CVC）を入力してください。 |
| incomplete_expiry | 有効期限を入力してください。 |
| processing_error | 決済処理中にエラーが発生しました。しばらくしてから再度お試しください。 |
| （その他） | カード情報をご確認ください。 |

### サーバー側エラーメッセージ

| コード | 表示文言 |
|---|---|
| card_limit_reached | お支払い方法は2枚まで登録できます。 |
| stripe_not_configured | 現在お支払い方法の登録を受け付けられません。しばらくしてから再度お試しください。 |
| stripe_error | 処理に失敗しました。しばらくしてから再度お試しください。 |
| last_card_with_active_subscription | 有効なサブスクリプションがある間は、最後の1枚のカードを削除できません。先に別のカードを登録してから削除してください。 |
| swap_requires_two_cards | 入れ替えにはカードが2枚登録されている必要があります。 |
| forbidden | お支払い方法の管理はアカウント管理者のみ実行できます。 |
| 通信エラー | 通信エラーが発生しました。しばらくしてから再度お試しください。 |

## カード削除

削除確認モーダル「カードの削除」。本文: 「{ブランド} •••• {下4桁}（{優先度}） を
削除しますか？」

**有効なサブスクリプションがある間は、最後の1枚のカードを削除できない**（409エラー、
上記メッセージ）。解約済みアカウントの場合は最後の1枚も削除できる。

なお、アカウント自体を解約した場合は、この画面での手動削除を待たず**登録済みの
カードがすべて自動的に削除される**（2026-08-22実装。詳細は外部仕様_解約.md・
内部仕様_解約.md参照）。

## プライマリ／バックアップの入れ替え

カードが2枚登録されている場合のみ「プライマリ／バックアップを入れ替える」ボタンが
表示される。押下でその場で入れ替わる（送信中「入れ替え中...」）。
