# 外部仕様: お知らせ

最終更新日: 2026-09-05
コード参照: announcements.html, js/role-nav.js, dashboard.html等サイドバーを持つ全画面

## サイドバーメニュー

サイドバーフッターの「アップグレード」の直上に「お知らせ」メニューを追加する
（メールアイコン）。全ロール（管理者・編集者・承認者・閲覧者）で操作可能
（「アップグレード」のようなロール別非表示は行わない）。

未読のお知らせがある場合、メニューのアイコン右側に赤いドットを表示する。
**未読件数（バッジ数字）は表示しない**（有無のみ）。

クリックすると`announcements.html`（お知らせ一覧）へ遷移する。

## announcements.html（お知らせ一覧画面）

見出し「お知らせ」。リード文: 「投稿の失敗など、確認が必要な出来事をお知らせします。
タイトルにマウスを合わせると、詳しい内容を確認できます。」

お知らせは新しい順に一覧表示され、各項目はタイトルと日時のみを表示する。
**項目にマウスオン（またはキーボードフォーカス）するとホバーカードが開き、
本文全体を表示する**（クリックでの詳細画面遷移は無い）。

お知らせが1件も無い場合: 「お知らせはまだありません。」

一覧画面を開いた時点で、当該ユーザーの未読状態を解消する（サイドバーの赤い
ドットも即座に消える）。

## 対象イベント（当面）

**投稿失敗のみ**。以下の条件を満たした投稿が対象（一時的な失敗・再試行中は対象外、
最終的に失敗が確定した時点でのみお知らせを作成する）:

- ワンショット投稿（即時投稿）: 実行時に失敗した場合（再試行は無いため即・最終結果）
- 予約投稿（スケジュール投稿・承認経由の投稿含む）: 初回失敗後、3分間隔で
  最大3回まで自動再試行される仕組みがあり、**その3回の再試行をすべて使い切って
  打ち止めになった時点**でのみお知らせを作成する（再試行中の各失敗では作成しない）

**過去に遡っての一括作成は行わない**。本機能導入以降に新たに発生した失敗のみが
対象。

## お知らせの内容（例）

```
タイトル: Xへの投稿が失敗しました (2026/08/21 131503)
本文:
TimeStamp: 2026/08/21 131503
SNS: X
対象: スケジュール「サンプルスケジュール」（ワンショット投稿の場合は「ワンショット投稿」）
Results: 失敗
Detail: {"title":"Unauthorized","type":"about:blank","status":401,"detail":"Unauthorized"}
Body: (投稿本文)
```

`Detail`はSNS側APIが返した生のエラー内容（可能な場合。取得できない場合はエラー
メッセージ全体）。
