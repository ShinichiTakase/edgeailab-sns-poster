# 外部仕様: アップグレード

最終更新日: 2026-08-22（更新: reason=payment_required追加・トライアルバーリンク修正を反映）
コード参照: upgrade.html, change-plan.html

## upgrade.html（初回本契約手続き画面）

トライアル中の顧客がお支払い情報を登録し本契約へ進むための画面。ダッシュボード等の
リンクからではなく、**主にサーバー側の自動リダイレクトでこの画面に到達する**
（後述）。

見出し「本契約のお手続き」。本文: 「トライアル終了後もサービスをご利用いただくには、
お支払い情報のご登録が必要です。次の画面でカード情報を入力いただきます。」
現在のプラン表示: 「選択中プラン: {プラン名}」。

### クエリパラメータによる案内文の出し分け

| クエリ | 表示文言 |
|---|---|
| billing=cancelled | お手続きがキャンセルされました。準備ができましたら、あらためてお進みください。 |
| reason=duplicate_account | このSNSアカウントは既にご利用済みのため、お支払い情報のご登録が必要です。 |
| reason=trial_expired | 無料トライアル期間が終了しているため、SNS連携にはお支払い情報のご登録が必要です。 |
| reason=payment_required | 解約後の再登録には、お支払い情報のご登録が必要です（無料トライアルの対象外です）。（2026-08-22追加） |

**`reason=trial_expired`の実際の遷移経路**: トライアル終了かつ支払い未登録の状態で
SNS連携（OAuth）を開始しようとした際、サーバー側で自動的にこの画面へリダイレクトされる
（外部仕様_無料で始める（トライアル）.md参照）。

**`reason=payment_required`の実際の遷移経路**（2026-08-22追加、外部仕様_解約.md・
外部仕様_サインアップ.md参照）:
- 解約済みアカウントを同一メールアドレスで再登録した直後、サインアップ完了レスポンスを
  受けてフロント側（signup.html）が`dashboard.html`ではなくこの画面へ直接遷移させる
- 上記の状態（トライアルを経由しない再登録・未決済）のまま、SNS連携（OAuth）開始や
  スケジュール投稿作成等の書き込み操作を試みた場合も、サーバー側で同様にこの画面へ
  リダイレクトされる

**ダッシュボード等のトライアル終了バーの「お支払い情報を登録する」リンクは、この画面
（upgrade.html）ではなく`payment.html`（お支払い方法の管理画面）へ遷移する**
（2026-08-22修正。それまではhref="#"のまま未実装だった。ダッシュボードの「ご利用の
流れ」STEP3にある既存の正しいリンクと同じ遷移先に揃えた形。トライアル中にカードだけ
先に登録しておきたい場合の導線であり、実際に本契約に進む場合はupgrade.htmlまたは
change-plan.htmlからの手続きが必要な点に注意）。

ボタン「カード情報を登録して本契約する」押下で、Stripeがホストする決済画面へ遷移する
（本画面自体にはカード入力フォームは無い）。失敗時: 「お手続きの開始に失敗しました。
しばらくしてから再度お試しください。」

## change-plan.html（プラン変更画面）

見出し「プラン変更」。リード文: 「現在ご契約中のプランより上位のプランへ変更できます。
プランのダウングレード（現在より下位のプランへの変更）には対応していません。」

### プランカード（Basic / Standard / Advanced）

| プラン | 基本料金 | 接続可能SNS数 | 投稿後課金 | 管理ユーザー数 |
|---|---|---|---|---|
| Basic | ¥480／月〜（税抜） | 1 | ¥30／投稿（上限なし） | 1名のみ |
| Standard | ¥980／月〜（税抜） | 3 | ¥30／投稿（月150投稿まで）、151投稿目以降¥20／投稿（上限なし） | 最大3名 |
| Advanced | ¥1,480／月〜（税抜） | 5 | ¥30／投稿（月180投稿まで）、181投稿目以降¥20／投稿（上限なし） | 最大5名（2026-08-27改修、旧: 最大3名） |

試算例（Standard）: 「3プラットフォームで月200投稿 ¥980 + (¥30×150 + ¥20×50) =
¥6,480／月 ※Xサーチャージは含みません」

### プランごとのボタン状態

- 現在のプラン: 「現在のプラン」バッジのみ
- アップグレード可能（上位プラン）: 「このプランに変更する」ボタン（有効）
- ダウングレード相当（下位プラン）: 「選択できません」ボタン（**無効**）＋注記
  「※ダウングレードには対応していません」

### 確認モーダル

- トライアル中の場合: 「変更後の月額基本料金：¥{金額}／月〜（税抜）／トライアル終了後、
  このプランで請求が開始されます。」
- 契約中（本稼働）の場合: 「プラン変更は今すぐ反映されます。今回のご請求への追加料金は
  発生しません。／次回のご請求日（{日付}）から、新プラン「{プラン名}」の基本料金
  ¥{金額}／月でご請求します。」（**日割り計算は行われない**旨が明記されている）

ボタン「キャンセル」「変更する」。成功時は画面をリロード。失敗時「プラン変更に
失敗しました。しばらくしてから再度お試しください。」
