# 外部仕様: サインアップ

最終更新日: 2026-08-22（更新: 解約後再登録時の遷移先変更を反映）
コード参照: signup.html, verify-pending.html, dashboard.html, upgrade.html

## 公開ページからの登録導線（2026-10-01）

- index.htmlの「無料で始める」「無料で始めよう」とpricing.htmlヘッダーの「無料で始める」はsignup.htmlへ遷移する（初期選択はStandard）。
- pricing.htmlの各プランの「無料トライアルを試す」は、選んだBasic・Standard・Advancedをサインアップ画面で初期選択する。
- これらのボタンではメンテナンス案内を表示しない。

## 画面構成（signup.html）

- プラン選択（Basic / Standard / Advanced のセレクトボックス。URLの`?plan=`クエリで初期値を
  指定可能。不正な値は"standard"にフォールバック）
- 入力項目
  - 会社名（任意）
  - お名前（必須）
  - メールアドレス（必須）
  - パスワード（必須。入力するたびに要件チェックリストがリアルタイムで更新される）
  - パスワード（確認用）（必須）
- 利用規約・プライバシーポリシーへの同意文言（リンククリックでモーダル表示、送信ボタン自体に
  同意チェックボックスはなく、送信をもって同意したものとみなす文言のみ）
- 送信ボタン「無料トライアルを始める」

## 入力バリデーション（フロント側・即時表示、サーバー側でも再検証）

- プラン: basic/standard/advancedのいずれか
- お名前: 3文字以上
- メールアドレス: 簡易形式チェック（`x@y.z`パターン）
- パスワード確認: パスワードと完全一致
- パスワード要件（すべて満たす必要あり。リスト表示で満たすたびに「レ」マークが付く）
  - 半角英大文字を1文字以上
  - 半角英小文字を1文字以上
  - 数字を1文字以上
  - 記号を1文字以上
  - 8文字以上

## エラーメッセージ

| 状況 | 表示文言 |
|---|---|
| プラン未選択相当 | ご希望のプランを選択してください。 |
| お名前3文字未満 | お名前は3文字以上で入力してください。 |
| メール形式不正 | メールアドレスの形式が正しくありません。 |
| パスワード不一致 | 入力されたパスワードが一致しません。 |
| パスワード要件未達 | パスワードは半角英大文字・半角英小文字・数字・記号をすべて含む8文字以上で入力してください。 |
| サーバー側: メール重複（409） | このメールアドレスは既に登録されています。<a>ログインはこちら</a> |
| サーバー側: その他 | 登録に失敗しました。しばらくしてから再度お試しください。 |
| 通信エラー | 通信エラーが発生しました。しばらくしてから再度お試しください。 |

## 登録完了後の挙動

- 送信成功時、確認メール等を待たずに即座にログイン状態となる（メール未認証のまま
  閲覧できる）
- 通常の新規登録は `dashboard.html` へ遷移する
- **解約済みアカウントを同一メールアドレスで再登録した場合**（2026-08-22仕様変更）は
  `dashboard.html`ではなく`upgrade.html?reason=payment_required`へ直接遷移する。
  この場合トライアルは付与されず、案内文「解約後の再登録には、お支払い情報のご登録が
  必要です（無料トライアルの対象外です）。」が表示される。詳細は
  外部仕様_無料で始める（トライアル）.md・外部仕様_解約.mdを参照
- ダッシュボードでは未認証の間、ステータスバーで案内され「認証メールを再送信」操作ができる
  （外部仕様_無料で始める（トライアル）.md、外部仕様_ダッシュボード.md参照）
- メール内の認証リンクをクリックすると `GET /api/auth/verify` にアクセスし、成功時は
  そのままログイン状態で `dashboard.html` へリダイレクトされる。失敗時は
  `verify-pending.html?error=...` へリダイレクトされる

## メール未認証の画面（verify-pending.html）

通常はダッシュボードへの直接遷移のためこの画面は使われないが、認証リンクの検証に
失敗した場合の着地点として存在する。

- 表示文言「{email} 宛に確認メールをお送りしました。メール内のリンクをクリックすると、
  認証が完了します。」
- エラー時の追加メッセージ（`?error=`クエリに応じて出し分け）
  - `missing_token`: 認証リンクが正しくありません。
  - `invalid_token`: 認証リンクが無効です。再送信してもう一度お試しください。
  - `expired_token`: 認証リンクの有効期限が切れています。再送信してください。
  - `internal_error`: 認証処理でエラーが発生しました。時間をおいて再度お試しください。
- 「認証メールを再送する」ボタン（60秒のクールダウンあり）
- 「メール未認証のまま続ける」リンク（dashboard.htmlへ）

## 権限・ロール

- サインアップした本人は、自アカウントの「管理者」ロールとして作成される
  （他メンバーを招待できる最上位ロール。外部仕様_メンバーを招待する.md参照）

## 要確認事項

- 利用規約・プライバシーポリシーへの同意について、送信ボタン自体には同意チェックボックスが
  なく、モーダル内の文言と送信操作をもって同意とみなす設計になっている（法的な十分性は
  仕様書の範囲外につき要確認）
