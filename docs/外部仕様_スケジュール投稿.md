# 外部仕様: スケジュール投稿

最終更新日: 2026-08-24（更新: 投稿結果メール通知設定を追加）
コード参照: schedule-list.html, schedule-form.html, schedule-detail.html

## 概要

曜日・時間帯枠を指定し、登録済みの投稿文章をラウンドロビン方式で消化しながら
継続的に自動投稿する機能。3画面構成: 一覧（schedule-list.html）→設定
（schedule-form.html）→詳細・投稿文章管理（schedule-detail.html）。

## 一覧画面（schedule-list.html）

初回訪問時は使い方説明ステップを表示（同一セッション中の再訪では省略）。

### 使い方説明（3ステップ、原文）
1. スケジュール設定「スケジュール名、投稿するSNS、URL付きかどうか、投稿期間、曜日、
   投稿時間帯枠（1日の投稿回数分）を設定します。」
2. 投稿文章登録「設定した曜日・時間帯枠に従って自動投稿される文章を、ラウンドロビン
   方式（登録した順に1件ずつ消費される形）で最大{n}件登録します。URL指定時は
   [AI文案生成]がURLを読み取り各SNSに最適化した文案を生成します（文案は修正できます）。
   URL未指定時は原文から[AI文案生成]、またはお客様が直接入力できます。**Instagramへは
   リール（動画）として自動投稿されるため、他のSNSとは異なりAIが自動で動画を
   生成します。**」（`{n}`はサーバー設定`DOCS_NUMBER`と連動、デフォルト5）
3. 自動投稿「設定した曜日・時間帯に従って、登録した投稿文章が順番に自動投稿され
   続けます。」

### スパム回避についての案内（原文）
- 自動投稿自体は各SNSポリシー上問題ない（いいね・コメント・フォロー自動化やDM大量送信の
  みが問題という説明）
- 「投稿時間帯」設定を30分以上にとることでランダム配信によりスパム検知リスクを下げる
- 投稿文章は内容の異なる複数を登録すべき（最大{n}件のラウンドロビン、AI文案生成が
  切り口の異なる文章を自動生成する旨）
- 「1日の投稿回数は最大3回までに制限しています。同一アカウントが短期間に投稿しすぎる
  ことによるスパム判定リスクを避けるための設計上の上限です。」

### 一覧テーブル

列: スケジュール名（ステータスpill付き）、登録済み投稿数、登録者メール、登録日、
一時停止/再開、削除。空状態「登録済みのスケジュールはまだありません。」

ステータスpill: 自動停止中（赤系、トライアル終了・支払い未登録による自動停止）／
一時停止中（オレンジ系、ユーザーによる手動停止）

「スケジュール追加」ボタンはSNS未連携時はクリックしても遷移せず、ツールチップ
「SNS連携を行ってください」を表示。

削除確認モーダル: 「『{名前}』を削除します。登録済みの投稿文章もすべて削除され、
元に戻せません。よろしいですか？」

## 設定画面（schedule-form.html）

新規/編集で見出し・送信ボタンが「スケジュール追加／登録」⇔「スケジュール編集／更新」に
切り替わる。

### 入力項目
- スケジュール名（テキスト）
- 投稿SNS（連携済みSNSのみチェックボックス。Instagramは「Instagram(リール)」表記）
- Facebook投稿先ページ（連携ページが2件以上のときのみ選択UI表示、1件なら自動選択）
- 「URL付きの投稿にする」チェックボックス。ヒント: 「投稿文章登録画面で『URL入力欄』か
  『原文入力欄』のどちらを表示するかの切り替えにのみ使います。Xサーチャージの課金は、
  実際に送信する投稿本文の内容から自動判定されます。」
- 「投稿後結果をメールで知らせる」チェックボックス（2026-08-24追加）。ヒント行に
  通知先として現在ログイン中のメールアドレスを表示（宛先の変更はできない、常に
  ログイン中のメールアドレス固定）
- 投稿開始日（デフォルト今日）／投稿終了日（空欄可、「指示があるまで継続」）
- 曜日（チップ選択＋「毎日」一括チェック）
- 1日の投稿回数（1〜3回、選択に応じて時間帯枠1〜3が動的表示）
- 各時間帯枠: 時（プルダウン）＋分（候補00/10/20/30/40/50、直接入力も可）。開始時刻選択時、
  終了未入力なら自動で開始+1時間を補完。ヒント: 「指定した時間帯の中からランダムな時刻に
  配信されます。配信が指定範囲より前後する場合があります。各枠は最低30分以上の幅で
  設定してください。」

### バリデーションエラー（上から順にチェック）
| 状況 | 表示文言 |
|---|---|
| 名前未入力 | スケジュール名を入力してください。 |
| SNS未選択 | 投稿先SNSを1つ以上選択してください。 |
| 開始日未入力 | 投稿開始日を指定してください。 |
| 終了日が開始日より前 | 投稿終了日は投稿開始日以降の日付を指定してください。 |
| 曜日未選択 | 曜日を1つ以上選択してください。 |
| 投稿期間内に指定曜日が1日も含まれない | 投稿は実行されません。投稿期間と曜日を確認してください |
| 時間帯未設定 | 投稿時間帯をすべて設定してください。 |
| 枠幅30分未満 | 投稿時間帯の各枠は最低30分以上の幅で設定してください。 |

失敗時: 「登録に失敗しました。入力内容をご確認のうえ再度お試しください。」

## 詳細画面（schedule-detail.html）

概要カード（投稿SNS・投稿期間・曜日・投稿時間帯・状態）＋投稿文章一覧。

状態説明（ツールチップ）:
- 稼働中: 「現在このスケジュールに沿って自動投稿が実行されています」
- 一時停止中: 「一時停止中のため、自動投稿は行われません」
- 自動停止中: 「トライアル終了またはお支払い未登録のため、自動投稿が停止しています」

投稿文章一覧は各エントリをプラットフォーム別40字抜粋で表示、生成元（URL/原文の抜粋）が
連続する場合は先頭にのみ区切り見出しを表示。

### 投稿文章の追加（一括、最大{n}件・{n}はサーバー設定値と同期必須）

プラットフォームごとにタブUI（未入力タブに`!`バッジ）。**タブ切替は独立して行われ、
1タブ=1回のAI生成**（生成中は他タブへの切替を禁止。理由: 生成中に他タブへ切替えると
裏で他プラットフォーム分も生成済みになっていて紛らわしいという指摘への対応）。

- テキストタブ: 通常のテキストエリア入力（AI文案生成ボタンあり）
- Instagramタブ: 動画専用（AI生成の対象がテキストではなく動画そのものになる）。
  スロットごとにステータス（順番待ち／生成中.../動画表示／キャンセルされました／
  生成に失敗しました）。done/error時のみ「再作成」ボタン表示
- **背景画像（2026-08-28追加、スロット単位）**: 各スロットの枠にドラッグ&ドロップ、
  または枠下の「＋ 背景画像」ボタンから個別に画像を指定できる（jpg/png/webp、8MBまで）。
  5スロットそれぞれに異なる画像を指定可能で、指定したスロットだけその画像が背景になる
  （テキストは常に白＋半透明の黒スクリムで表示され、どんな画像でも読みやすさを確保）。
  未指定のスロットは従来通りAIが投稿文の雰囲気からアクセントカラーを自動選択する。
  生成中（順番待ち／生成中...）のスロットは背景画像を変更できない
- 「AI動画生成」ボタン押下で生成開始（案内「動画の生成に5分から10分かかる場合が
  あります。」）。完了時トースト表示＋（タブを見ていなければ）タブタイトル点滅。
  完了メッセージ: 「Instagram動画の生成が完了しました（{done} / {n} 本）。」
- サーバー再起動等でジョブが消失していた場合: 「動画生成の進捗を確認できませんでした
  （サーバーが再起動された可能性があります）。お手数ですが、もう一度[AI動画生成]から
  やり直してください。」
- 保存条件: 全プラットフォームのテキストタブが全件入力済み、かつInstagram選択時は
  全スロット完了。未完了時のヒント例: 「保存するには、Threads・Xタブの投稿文章・
  Instagramタブの動画もすべて入力・生成してください。」
- 保存ボタン: 編集者ロールは「承認依頼」、それ以外は「保存」
- 離脱保護: 未保存の入力・生成中/完了済みコンテンツがある状態でページを離れようとすると
  確認ダイアログ。「スケジュール設定を編集」リンクも生成中はクリック時に専用確認モーダル
  （「文案・動画を生成中です／生成中に画面を離れると、作成中のデータは保存されません。
  よろしいですか？」）

### 投稿文章の編集（単一）

既存1件の文章修正・単一AI再生成。Instagramが動画付きなら背景画像アップロード欄
（任意、未指定ならAI自動生成）＋再作成ボタン、未設定なら画像アップロード
（ドラッグ&ドロップ対応、jpg/png/webp、8MBまで）。承認不要（単発の
追加・再生成用途）。当日分が既に生成済みの場合「本日分は生成済みのため、この編集は
明日以降の投稿に反映されます」の注記あり。

## 投稿結果メール通知（2026-08-24追加）

「投稿後結果をメールで知らせる」がオンのスケジュールは、投稿1件ごとの最終結果
（成功、または自動再試行3回を打ち止めた後の失敗）を、スケジュール作成者のメール
アドレスへ通知する。再試行の途中経過（1回目・2回目の失敗）では送信しない。

- 件名: 「【EdgeAI Lab】予約投稿が完了しました」／「【EdgeAI Lab】予約投稿が失敗しました」
- 本文: スケジュール名・投稿先SNS・投稿内容、失敗時は追記で「自動で再試行を行いましたが、
  投稿できませんでした。内容をご確認のうえ、必要に応じてスケジュール設定を見直して
  ください。」
- 対象はスケジュール投稿由来の予約のみ。ワンショット投稿の予約投稿（同じ
  `scheduled_posts`を使うが起点がスケジュールではない）は対象外
- メール送信に失敗しても投稿処理自体の成否には影響しない（送信失敗はログのみ）

## AI生成エラーメッセージ（ワンショット投稿と共通辞書）

| コード | 表示文言 |
|---|---|
| url_fetch_failed | URLの内容を取得できませんでした。URLをご確認のうえ再度お試しください。 |
| url_not_found | 指定されたURLのページが見つかりません（404）。URLを確認してください。 |
| url_access_denied | このページはアクセスが制限されており、内容を取得できません。 |
| url_fetch_timeout | ページの読み込みがタイムアウトしました。しばらくしてから再度お試しください。 |
| url_server_error | ページの取得中にエラーが発生しました（サーバーエラー）。しばらくしてから再度お試しください。 |
| url_content_too_short | ページから十分な内容を取得できませんでした。別のURLをお試しいただくか、本文を直接入力してください。 |
| ai_not_configured | AI文案生成は現在ご利用いただけません。 |
| ai_refusal | この内容の文案は生成できませんでした。内容を変えて再度お試しください。 |
| ai_output_truncated | 文案が長すぎたため生成できませんでした。選択するSNSを減らすか、原文を短くして再度お試しください。 |
| ai_timeout | 文案の生成に時間がかかりすぎたため中断しました。しばらくしてから再度お試しください。 |
| ai_rate_limited | 現在AIへのアクセスが集中しています。しばらくしてから再度お試しください。 |
| ai_server_error | AIによる生成中にエラーが発生しました（サーバーエラー）。しばらくしてから再度お試しください。 |
| ai_connection_error | AIサービスへの接続に失敗しました（ネットワークエラー）。しばらくしてから再度お試しください。 |
| instagram_media_required | Instagramの投稿には画像または動画が必須です。 |
| text_required | すべてのプラットフォーム分の投稿文を入力してください。 |
| no_approver_configured | 承認者が設定されていません。管理者にお問い合わせください。 |

## 権限・ロールによる違い

- 編集者: 投稿文章の一括追加は必ず承認依頼を経由（保存ボタンが「承認依頼」に変わる）。
  単一エントリの編集・再生成は承認不要
- 閲覧者: 書き込み系操作はサーバー側でブロックされる（外部仕様_ワークフロー.md参照）

## 要確認事項

- 一括追加の最大件数（{n}）はサーバー設定`DOCS_NUMBER`（デフォルト5）と連動しており、
  画面の説明文言中にも動的に反映される
