# 外部仕様: パスワード変更

最終更新日: 2026-08-22
コード参照: change-password.html

## 画面構成

ダッシュボード等と共通のサイドバーを持つ設定画面（`change-password.html`）。
プロフィールメニューの「パスワード変更」リンクから遷移する。

- 入力項目
  - 現在のパスワード（必須）
  - 新しいパスワード（必須。入力に応じてリアルタイムで要件チェックリストが更新される）
  - 新しいパスワード（確認用）（必須）
- 送信ボタン「変更」→ フロント側バリデーション通過後、確認モーダルを表示

## パスワード要件（新しいパスワード）

サインアップ・パスワード再設定と同一基準:
- 半角英大文字を1文字以上
- 半角英小文字を1文字以上
- 数字を1文字以上
- 記号を1文字以上
- 8文字以上

## 確認モーダル

タイトル「パスワード変更の確認」、本文「パスワードを変更しますか？」。
「キャンセル」「変更」の2ボタン。実際のAPI呼び出しはこのモーダルの「変更」押下時に行われる
（フォーム送信ボタンは確認モーダルを開くだけ）。

## エラーメッセージ

| 状況 | 表示文言 |
|---|---|
| 現在のパスワード未入力 | 現在のパスワードを入力してください。 |
| 新パスワード不一致 | 新しいパスワードが一致しません。 |
| 新パスワード要件未達 | 新しいパスワードは半角英大文字・半角英小文字・数字・記号をすべて含む8文字以上で入力してください。 |
| サーバー: 現在のパスワード誤り | 現在のパスワードが正しくありません。 |
| サーバー: その他 | パスワードの変更に失敗しました。しばらくしてから再度お試しください。 |
| 通信エラー | 通信エラーが発生しました。しばらくしてから再度お試しください。 |

セキュリティ配慮として、送信の成功・失敗・通信エラーいずれの場合も、3つの入力欄は
必ず空にリセットされる。

## 成功時の挙動

フォームを非表示にし、「パスワードを変更しました。」というメッセージ枠を表示する
（ページ遷移はしない）。

## セッションへの影響

- 変更を行った本人の現在のセッションはログアウトされず、そのまま継続して利用できる
- ただし、他デバイス・他ブラウザで開いていた既存セッションは全て無効化される
  （内部仕様参照）

## その他

- APIが401を返した場合（セッション切れ等）は`login.html`へ自動遷移する
