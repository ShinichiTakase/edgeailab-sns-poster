# 外部仕様: フッター

最終更新日: 2026-08-24（新規作成）
コード参照: index.html, features.html, pricing.html, faq.html

## 概要

ログイン不要の公開4ページ（トップページ・機能ページ・料金ページ・FAQページ）共通の
フッター。4ページとも同一内容（実装は各ページの`<footer>`に個別重複。内部仕様参照）。
ログイン後のダッシュボード等サイドバー使用ページにはフッターは無い。

## フッターメニュー（法定リンク）

いずれも実際のページ遷移ではなく、その場でモーダルを開く形式（送信ボタンではない）。

| 表示テキスト | 内容 |
|---|---|
| プライバシーポリシー | 個人情報の定義・取得情報・利用目的・SNSプラットフォームへの送信について・OAuth認証情報の安全管理など全14項目 |
| 特定商取引法に基づく表記 | 事業者名・連絡先・料金・支払方法等の法定表記 |
| 利用規約 | サービス内容・利用登録・投稿コンテンツの取り扱い・禁止事項等の条文 |

モーダルは背景クリック・×ボタン・Escキーのいずれでも閉じる。

## SNSアイコンリンク

フッターメニューの下に、EdgeAI Lab公式アカウントへのアイコンリンクを設置。いずれも
`target="_blank"`で別タブが開く外部リンク（メールのみ`mailto:`）。

| アイコン | リンク先 | 備考 |
|---|---|---|
| メール | `mailto:info@edgeailab.net` | 問い合わせ用 |
| X | `https://x.com/messages/compose?recipient_id=...` | 投稿ではなくDM作成画面へ直接遷移 |
| Threads | `https://www.threads.net/@edgeai_lab` | プロフィールページ |
| Facebook | `https://m.me/EdgeaiLabOfficial` | Messengerでのメッセージ作成画面 |
| LinkedIn | `https://www.linkedin.com/company/edgeai-lab/` | 会社ページ |
| Instagram | `https://www.instagram.com/direct/t/edgeai_lab/` | DM作成画面へ直接遷移 |

**X・Facebook・Instagramは、投稿の閲覧ではなく直接メッセージ（DM）を送るための
URLになっている**点に注意（2026-08-24修正。修正前はプロフィールページへのリンクに
なっていた）。
