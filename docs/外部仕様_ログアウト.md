# 外部仕様: ログアウト

最終更新日: 2026-08-22
コード参照: dashboard.html（プロフィールメニュー内「ログアウト」ボタン）

## 導線

ダッシュボード等のプロフィールメニュー内「ログアウト」ボタン（全ロールに表示。
解約ボタンと異なり権限制限はない）。

## 挙動

ボタン押下で即座に`POST /api/auth/logout`を呼び出し、成否に関わらず`login.html`へ
遷移する（確認モーダル等の追加ステップはない）。

ログアウトAPI自体が通信エラー等で失敗した場合でも、フロント側は例外を握りつぶして
そのまま`login.html`へ遷移する（コードコメント: 「ログアウトAPIが失敗してもクライアント側の
セッションCookieが残るだけなので、ログイン画面への遷移は続行する」）。

## 要確認事項

- ログアウトAPIが失敗した場合、ブラウザ上のセッションCookieがクリアされないまま
  ログイン画面に遷移する可能性がある（上記の通り許容された仕様）。ユーザーが再度
  `dashboard.html`等に直接アクセスした場合、Cookieが有効なままログイン状態に戻って
  しまう可能性があるが、通常の通信環境ではAPI呼び出し自体の失敗は稀と考えられる
