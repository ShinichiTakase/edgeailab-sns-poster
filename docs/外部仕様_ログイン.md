# 外部仕様: ログイン

最終更新日: 2026-08-22
コード参照: login.html, forgot-password.html, reset-password.html

## ログイン画面（login.html）

- 入力項目: メールアドレス、パスワード（いずれも必須）
- 送信ボタン「ログイン」
- 「パスワードを忘れた方はこちら」→ forgot-password.html
- 「アカウントをお持ちでない方は 料金プランを見る」→ pricing.html

### エラーメッセージ
- 認証失敗（メール・パスワード不一致、または未登録メール）: 「メールアドレスまたは
  パスワードが正しくありません。」（存在有無を区別しない統一メッセージ）
- 通信エラー: 「通信エラーが発生しました。しばらくしてから再度お試しください。」

### ログイン成功後
- `dashboard.html`へ遷移

### ログイン可能な対象者
- アカウント本人（customers.email）だけでなく、招待され承諾済みのメンバー（users[].email）も
  同じ画面からログインできる

## パスワード再設定申請画面（forgot-password.html）

- 入力項目: メールアドレスのみ
- 送信ボタン「パスワード再発行」
- 送信後の表示（成功・未登録いずれも同一文言。登録有無を外部に漏らさないため）:
  「ご入力のメールアドレスが登録されている場合、パスワード再設定用のメールを送信しました。
  メールをご確認ください。」
- 送信後は180秒のクールダウン（ボタンに「再送信できるまで◯秒」を表示し無効化）
- 短時間の連続送信（レート制限超過、429）時: 「しばらく時間をおいて再度お試しください。」
  （こちらも180秒クールダウン）
- メールアドレス形式不正: 「メールアドレスの形式が正しくありません。」

## 新しいパスワードの設定画面（reset-password.html）

メール内のリンク（`?token=`付き）からのみアクセスする想定の画面。

- 画面表示前にトークンの有効性を`GET /api/auth/password-reset-info`で確認し、無効な場合は
  フォームを表示せずエラー案内のみを出す
  - トークン欠如: 「パスワード再設定用のリンクが正しくありません。再度パスワード再発行
    手続きを行ってください。」＋forgot-password.htmlへの案内リンク
  - 無効・期限切れ: 「リンクの有効期限が切れています。再度パスワード再発行手続きを
    行ってください。」＋同案内リンク
- 有効な場合のフォーム入力項目: 新しいパスワード、新しいパスワード（確認用）
  - パスワード要件チェックリストはサインアップ画面と同一（英大文字・英小文字・数字・記号
    各1文字以上、8文字以上。入力に応じてリアルタイムでチェックマーク表示）
- エラーメッセージ
  - パスワード不一致: 「入力されたパスワードが一致しません。」
  - 要件未達: 「パスワードは半角英大文字・半角英小文字・数字・記号をすべて含む8文字以上で
    入力してください。」
  - 送信時にトークンが失効していた場合: フォームを隠し「リンクの有効期限が切れています。
    再度パスワード再発行手続きを行ってください。」を表示
- 成功時: 「パスワードを再設定しました。」＋ログイン画面へのリンクを表示
- セキュリティ配慮として、送信後は入力欄のパスワードを画面上から必ずクリアする
  （成功・失敗・通信エラーいずれの場合も）
