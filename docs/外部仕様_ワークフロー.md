# 外部仕様: ワークフロー（承認）

最終更新日: 2026-08-22
コード参照: approval.html, my-requests.html

## 概要

編集者ロールが作成した投稿内容（スケジュール投稿の文章バッチ・ワンショット投稿）は、
直接保存されず承認者による承認を経て初めて自動投稿の対象になる。承認者は「承認」
「却下」を選べ、複数承認者が指定されている場合は**全員の承認が揃って初めて確定**する
（却下は1人でも成立する。内部仕様参照）。

## 承認画面（approval.html）

1つの画面が2つのモードで動作する。

### トークンモード（メール内リンクから、未ログインでもアクセス可）

`?token=`付きURLでアクセス。`GET /api/approvals/by-token/:token`で取得。

- 無効・期限切れ・判断済みの場合: 「このリンクは無効か、既に期限切れ・判断済みです。
  ログイン後、メニューの『承認待ち一覧』からご確認いただくか、依頼者に再送を依頼して
  ください。」＋ログインリンク
- 有効な場合、対象バッチのカードを表示し、**それとは別に自分が承認待ちの他のバッチが
  あれば**「他にも承認待ちが{n}件あります」を表示。ただし他バッチは依頼日時のみで
  内容・決定ボタンは表示されない（「詳細を見るにはログインしてください」）。全件まとめて
  確認するには「ログインしてメニューの『承認待ち一覧』をご利用ください」と案内

### 一覧モード（ログイン後、承認者ロールのメニュー「承認待ち一覧」から）

`GET /api/approvals/mine`で自分が承認待ちの全バッチを取得。空の場合「現在、承認待ちの
依頼はありません。」。1件決定しても、その場でカードの表示だけが更新され、一覧全体は
再読み込みされない。

### バッチカードの表示内容

- 依頼日時・期限（「依頼日時: YYYY/MM/DD HH:MM ／ 期限: YYYY/MM/DD HH:MM」）
- 内容: ワンショット投稿は1エントリ＝1プラットフォームの文章、スケジュール投稿の
  文章バッチは1エントリの中にX/Threads/Facebook/Instagramそれぞれの文章が並んで表示される
  （プラットフォームラベル: X／Threads／Facebook／Instagram）
- 却下時コメント欄（任意、プレースホルダー「却下する場合はコメントを入力できます（任意）」）
- ボタン「却下する」「承認する」

### 承認・却下後の表示

- 承認かつ全員揃った場合: 「承認しました。全員の承認が揃ったため確定しました。」
- 承認だが他の承認者の判断待ちの場合: 「承認しました。他の承認者の判断待ちです。」
- 却下時: 「却下しました。依頼者に通知します。」
- 決定後、そのカードのボタンは非表示になりコメント欄も無効化される（再決定不可）

### エラーメッセージ

| エラーコード | 表示文言 |
|---|---|
| already_decided | このバッチは既に判断済みです。 |
| expired | 承認期限が切れています。 |
| not_approver | この投稿の承認者に指定されていません。 |
| already_responded | 既に回答済みです。 |
| unauthenticated | ログインが必要です。 |
| （その他） | 処理に失敗しました。しばらくしてから再度お試しください。 |
| 通信エラー | 通信エラーが発生しました。 |

## 承認依頼一覧画面（my-requests.html、編集者向け）

見出し「承認依頼一覧」、リード文「あなたが送った承認依頼の状況です。却下・失効した依頼は、
内容を編集の上で再度依頼できます。」

- ステータス表示: 承認待ち（pending）／承認済み（approved）／却下（rejected）／
  失効（expired）
- 各カード: 種別（ワンショット投稿／スケジュール投稿）、依頼日時、ステータス、内容の
  抜粋（120文字超は「...」で省略）
- 却下された場合は却下コメント（あれば）を表示: 「却下コメント: {コメント}」
- 本画面上に承認・却下操作や再依頼専用ボタンはない（読み取り専用のステータス確認画面。
  再依頼は元の編集画面から改めて行う）
- 空の場合「承認依頼はまだありません。」

## メール通知

- 承認依頼作成時、各承認者に依頼メールが届く（件名「【EdgeAI Lab】投稿の承認依頼が
  届いています」。本文に72時間の期限案内あり）
- **却下時のみ**依頼者（編集者）に通知メールが届く（件名「【EdgeAI Lab】投稿の承認依頼が
  却下されました」）
- **72時間以内に承認されず失効した場合も**依頼者に通知メールが届く（件名「【EdgeAI Lab】
  投稿の承認依頼が失効されました」）
- 承認（部分承認・全員承認確定いずれも）が完了した場合の通知メールは**送信されない**
  （画面上の表示のみで完結する）

## 要確認事項

- 承認の期限は72時間（内部仕様参照）。画面上には期限の日時のみ表示され、「あと◯時間」
  のようなカウントダウン表示は無い
