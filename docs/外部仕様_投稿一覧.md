# 外部仕様: 投稿一覧

最終更新日: 2026-08-22
コード参照: post-list.html

## 概要

即時投稿・予約投稿（スケジュール投稿由来・ワンショット予約由来の両方）を横断した
履歴一覧。読み取り専用画面（削除・再試行・再生成などのアクションは無い）。

## 表示内容

統計カード: 総件数／投稿済み／予約中

テーブル列:
- 予約日時（レコード作成日時）
- 投稿者（メールアドレス）
- SNS
- アカウント（実際に投稿されたSNSアカウント名。予約が未実行の間は空欄）
- 投稿文（20字で省略、ホバー/フォーカスでポップオーバー表示し全文確認可能）
- 予定日時（`pending`状態の予約投稿のみ表示。即時投稿は「即時」表示）
- 投稿完了時間
- 結果

結果ラベル（色分けpill）:
| 値 | 表示 | 色 |
|---|---|---|
| success | 成功 | 緑 |
| failed | 失敗 | 赤 |
| retrying | 再投稿 | オレンジ |
| pending | 予約中 | グレー |

## 並び替え

「結果」列以外の全列はクリックでソート切替可能（昇順/降順表示あり）。日付系の列は
日時として、それ以外は日本語ロケールの文字列として比較する。

## ページネーション

**50件ごと**にページネーション。ステータス表示「{現在ページ} / {総ページ数}ページ
（全{件数}件）」。

## 空状態

「投稿履歴はまだありません。」

## 要確認事項

- 本画面にはアクション（削除・再試行等）が一切無い。再試行等が必要な場合は各投稿の
  発生元画面（スケジュール投稿詳細・ワンショット投稿）から改めて操作する想定と思われる
