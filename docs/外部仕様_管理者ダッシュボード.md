# 外部仕様: 管理者ダッシュボード（/admin/）

最終更新日: 2026-09-05
コード参照: edgeailab.net/admin/index.html, sns-poster/src/routes/adminStats.js

## 概要

`https://edgeailab.net/admin/` は運営者向けの管理画面。顧客向けダッシュボード
（`dashboard.html`）とは別の、Basic認証（nginx側、ユーザーID固定・パスワード共有）で
保護された領域。アプリ側にログイン機能・権限の概念は無い。

メニューペイン（暗めの赤の背景）とメインペインで構成。メニューペイン最上部には
EdgeAI Labロゴ・テキスト、最上段メニューは「ダッシュボード」（`/admin/`自身への
リンク）。

## ダッシュボードの表示内容

全て**暦月（カレンダー月）**基準の集計（顧客ごとのStripe請求サイクルとは異なる。
顧客ごとに決済日が違うため、全顧客横断の指標は暦月で揃えている）。

1段目:
- 現在の利用者数（解約済みを除く全顧客数）
- 前月の利用者数（現在の利用者数 − 前月中に解約した利用者数）

2段目:
- 前月の投稿数（SNS毎・合計）
- 今月の投稿数（今日まで、SNS毎・合計）

3段目:
- 前月の売上高（従量料金のみ。基本料金は含まない。SNS毎・合計）
- 今月の売上高（今日までの投稿数で計算。従量料金のみ）

4段目:
- Xサーチャージ（前月・今月今日まで）

**売上高はいずれも従量料金（投稿ごとの階層価格）のみで、プランの基本料金（固定額の
サブスクリプション料金）は含まない**（2026-09-05、ユーザー確認済み）。SNS毎の内訳は
按分による近似値（内部仕様参照）。
