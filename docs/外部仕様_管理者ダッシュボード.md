# 外部仕様: 管理者ダッシュボード（/admin/）

最終更新日: 2026-09-05（更新: 売上高に基本料金を追加、Xサーチャージを
「Xの従量料金」の内訳として統合）
コード参照: edgeailab.net/admin/*.html, sns-poster/src/routes/admin*.js

## 概要

`https://edgeailab.net/admin/` は運営者向けの管理画面。顧客向けダッシュボード
（`dashboard.html`）とは別の、Basic認証（nginx側、ユーザーID固定・パスワード共有）で
保護された領域。アプリ側にログイン機能・権限の概念は無い。

メニューペイン（暗めの赤の背景）とメインペインで構成。メニューペイン最上部には
EdgeAI Labロゴ・テキスト。メニュー構成（上から順）:
1. ダッシュボード（`/admin/`。本ファイル冒頭の集計表示）
2. 利用者一覧
3. 投稿一覧
4. パスワード初期化
5. Xサーチャージ
6. サーバーのリソース状況

## ダッシュボードの表示内容

全て**暦月（カレンダー月）**基準の集計（顧客ごとのStripe請求サイクルとは異なる。
顧客ごとに決済日が違うため、全顧客横断の指標は暦月で揃えている）。

1段目:
- 現在の利用者数（解約済みを除く全顧客数）
- 前月の利用者数（現在の利用者数 − 前月中に解約した利用者数）

2段目:
- 前月の投稿数（SNS毎・合計）
- 今月の投稿数（今日まで、SNS毎・合計）

3段目（2026-09-05改修: 基本料金追加、Xサーチャージ統合）:
- 前月の売上高（SNS毎の従量料金＋Xの行の下にXサーチャージ＋従量料金合計＋
  基本料金＋総合計）
- 今月の売上高（今日までの投稿数で計算。内訳は同様）

内訳の表示順（例）:
```
X:          ¥690
  Xサーチャージ: ¥736
Threads:    ¥660
Facebook:   ¥750
Instagram:  ¥660
LinkedIn:   ¥660
――――――――――
従量料金合計: ¥4,156
基本料金:    ¥3,440
――――――――――
合計:       ¥7,596
```

SNS毎の内訳（Xサーチャージを除く）は按分による近似値（内部仕様参照）。
Xサーチャージは実際のX URL付き投稿数から個別に計算した正確な金額。基本料金は
本稼働中の顧客のプラン別固定額の単純合計（按分不要）。

## 利用者一覧（/admin/users.html）

顧客（customers）一覧。クリックすると明細を表示する。システムの制御に関わる
細かい情報（Stripe ID・パスワードハッシュ・各種トークン等）は表示しない。

一覧の列: メールアドレス、氏名／会社名、プラン、ステータス（トライアル中／
本稼働中／解約済み）、利用開始日。

絞り込み: メールアドレス（部分一致）、ステータス（完全一致）。
ページネーション: 50件／ページ。新規登録が新しい順に表示。

明細: メールアドレス、氏名、会社名、プラン、ステータス、利用開始日、
トライアル終了日、解約日時、連絡先（登録されている全メンバーのメールアドレス・
氏名・権限）。

## 投稿一覧（/admin/posts.html）

全顧客横断の投稿履歴。新しい投稿から順に表示。ページネーション: 50件／ページ。

列: 日時、管理者のメールアドレス（投稿を実行した/しようとしたユーザーの
メールアドレス）、SNSの種類、結果（成功／失敗）。

**失敗の記録は2026-09-05以降に発生したもののみ**（ダッシュボードの「お知らせ」
機能と同じデータを利用しており、それ以前の失敗は記録が無い。内部仕様参照）。

## パスワード初期化（/admin/password-reset.html）

自分でパスワード再設定ができない利用者向けの機能。利用者のメールアドレスを
入力して「初期化」を押すと、新しいパスワードを生成し、そのパスワードを本人の
メールアドレス宛に送信する。管理者の画面上には新しいパスワードを表示しない
（メール本文でのみ案内する）。

## Xサーチャージ（/admin/x-surcharge.html）

表示する情報:
- 現在のsns-poster側のXサーチャージ額（円）
- Xの公式サイト（developer.x.com/#pricing）を見て管理者が手入力した参照値
  （ドル）。**自動取得はできない**（developer.x.comへの自動アクセスはHTTP 402
  Payment Requiredを返すため。2026-09-05実機確認済み）ため、値と最終更新日時を
  手入力・保存する
- 現在のドル円レート（自動取得、無料の為替レートAPIを使用）
- 実Xサーチャージ（参照値×レートを円換算した計算結果。表示のみ、保存はしない）

Xサーチャージの変更予約: 新しい金額（円）と予約日を入力して予約すると、
**予約日にStripeの実際の課金価格（全顧客のサブスクリプション）が自動的に
変更される**（表示上の設定を変えるだけでなく、本番の課金価格そのものを
変更する機能。内部仕様参照）。予約は1件のみ保持し、新しい予約は既存の予約を
上書きする。予約は取り消すこともできる。

## サーバーのリソース状況（/admin/server-resources.html）

CPUコア数・プロセッサの型番、load average（1分／5分／15分）、メモリ（使用量／
総量）、ストレージ（使用量／総量・使用率）をリアルタイムに表示する。
